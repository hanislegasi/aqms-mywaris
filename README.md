# AQMS - Al-Qawthar Management System

Sistem pengurusan untuk produk perancangan harta pusaka Islam
(Wasiat, Hibah, Harta Sepencarian, Mawaris).

Pemilik: Hasnawi Bin Che Harun
Dilesenkan kepada: Al-Qawthar Mawaris Synergy Sdn. Bhd.

## Portal
- Portal Customer (AQM)
- Portal Consultant (AQC)
- Portal Admin

## Teknologi
Firebase (Firestore, Auth, Functions, Storage), Tailwind CSS, hos GitHub Pages.
